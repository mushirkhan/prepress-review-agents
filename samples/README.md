# Sample artwork

Test files for the app, the automated tests and the evaluation. Upload any of them in the web app to see the agents work.

Every file is generated by `apps/api/scripts/generate-samples.ts` with known properties (size, bleed, DPI, colour space, printed text), so the expected result is known by construction. `manifest.json` holds the job ticket and the expected result for each file. Regenerate with:

```bash
npm run samples -w @prepress/api
```

The output is deterministic: running it again produces byte-identical files.

Brand names appear only as plain text in a generic font, to test the IP & Trademark agent. No real logos are drawn or stored here.
